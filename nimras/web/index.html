Speech models · benchmark gate · rollback

        
N.I.M.R.A.S. watches release feeds and research topics and recommends models. It never downloads or runs them; install a candidate yourself, benchmark it here, then promote it. The previous model is kept for rollback.

         
        

      

      
Privacy

        
Audio is processed locally and never stored, except recordings you explicitly save to the test set. Transcripts are kept in conversation history so follow-ups work.
